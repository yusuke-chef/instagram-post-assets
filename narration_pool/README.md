# ナレーションプール

リール完全自動化のための、事前録音済みナレーション音声の置き場所です。

## 使い方

1. 新しいリールのナレーションを録音したら、`pending/` フォルダに以下の**3ファイル1組**でアップロードしてください（この3点セットはClaudeが用意します。ナレーション録音後、その音声ファイルをこの3点セットに揃えるところまでClaudeに依頼してください）。
   - `<名前>.mp3`（録音した音声）
   - `<名前>_caption.txt`（投稿用キャプション。ハッシュタグ5個以内、社名は書かない）
   - `<名前>_prompts.txt`（Runway映像生成用の英語プロンプト、1行1カット、4行）
2. **ローカルcron（`scripts_local/local_autofill.py`、AIを介さない機械的な処理）**が定期的に`pending/`を確認し、3点セットが揃っているものから古い順に、Runwayで映像生成→組み立て→schedule登録→pushまで完全自動で行います。**目視確認は行われません**（見切れ等の不具合があってもそのまま投稿される可能性があります）。
3. 消費されたファイルは自動的に `used/` フォルダへ移動されます（同じ名前のファイルは二度使われません）。

## なぜこの仕組みが必要か

画像・動画生成はAPIキーがあれば自動化できますが、**ナレーションは内田様ご本人の声である必要があるため、これだけは人の手でしか用意できません**。そのため「後から追いつく」形ではなく、事前にまとめて録音してこのプールに入れておくことで、リールも在庫が尽きる前に自動で回るようにしています。

**ストックが7日分を切らないよう、時間のある時に数本まとめて録音・アップロードしていただくことをおすすめします。**
